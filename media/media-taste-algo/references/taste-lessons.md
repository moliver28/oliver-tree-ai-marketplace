# Taste lessons (accumulating, dated)

Format: `YYYY-MM-DD | lane/rule | evidence | instruction`. Add one line per
new pattern. Mark `UNCONFIRMED` below 3 data points. Read before any
algorithm edit. Fold duplicates instead of appending; prune stale rows when
touching the file. Standing, machine-invariant lessons carry a `(standing)`
marker instead of a date.

## Example rows (shapes, not content)

- YYYY-MM-DD | <lane> | "<Title A> 9, <Title B> 7" | weight the lane once one
  more point lands
- YYYY-MM-DD | anti-lane | "<Title C> 4" | demote the adjacent pattern even
  when affinity is high
- (standing) | config operators | trained_params.config keys | every
  operator surface is data: a verdict or pattern change is a sidecar edit
  plus a training run, never a script edit
