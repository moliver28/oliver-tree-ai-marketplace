# Method selection

The method-selection record for this study (checklist stage A0). The A0
gate reads this file: the classification table, the method line with the
alternatives, and the routing line. One row per research question; fill
the table before the method pick.

## Classification table

| Research question | Attitudinal or behavioral | Qualitative-direct or quantitative-indirect | Context of use | Time stage |
|---|---|---|---|---|
|  |  |  |  |  |

Attitudinal = what people say; behavioral = what people do.
Qualitative-direct = why and how to fix; quantitative-indirect = how many
and how much. Context of use: natural, scripted, limited, or
decontextualized. Time stage: generative/strategize, formative/design, or
summative/launch-and-assess.
