# Recruitment

Recruiting materials for this study.

- `participants.md` - the participant tracker. It holds one table per
  flow; the columns are the approved fixed sets from the template.
- `outreach-log.md` - every contact attempt, newest first. The recruit
  command inserts entries below the divider.

Rules:

- Status values must come from the vocabulary printed in
  `participants.md`; the recruit command validates them.
- Contact details (email, Slack handle) stay in this folder only.
  Never copy them into the ticket, chat, or a commit message.
- The participant key and raw transcripts live under `interviews/` and
  are gitignored; nothing in this folder replaces them.
