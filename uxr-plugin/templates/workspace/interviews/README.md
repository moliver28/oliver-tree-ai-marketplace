# Interviews

Session materials for this study.

- `<slug>-<date>-summary.md` - one summary per session (tracked in git).
- `raw-transcripts/` - raw transcripts; gitignored, never committed.
- `participant-key.md` - participant identities; gitignored, never
  committed.

Each summary ends with the research alignment block (insights mapped to
research questions, hypotheses, and assumptions); the report command
reads that block. Keep summaries free of personal contact details: they
are tracked, and git history is forever.
