# Analysis

Synthesis for this study lives here.

- `codes.md` - the codebook: one row per code, each anchored to cited
  evidence.
- `themes.md` - themes built from codes, with an evidence weight that
  only graduates when the evidence is saturated.

Rules:

- Every code's anchor example cites a source as `[S:<slug>]`.
- A theme moves to `graduated` only from `saturated` (5+ sources), and
  the move names the synthesis file that carries it.
- Prefer emerging codes over neat ones: the codebook grows from the
  data, not from the hypothesis list.
