# Deliverables

Reports, decks, cheat sheets, and other outputs for this study land
here.

- Name files so links stay stable: `<what>-<audience>-<YYYY-MM-DD>.md`.
- Distribution is drafts only: a deliverable reaches a tracker comment,
  chat, or mail only when the user approves that step.
- Every claim in a deliverable cites its evidence as `[S:<slug>]` from
  `sources/`.
